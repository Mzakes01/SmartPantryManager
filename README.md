
# Smart Pantry Manager

## Overview
Smart Pantry Manager is an Android application developed for the Mobile App Development 700 assignment. It helps users manage pantry ingredients and discover recipes they can prepare using the ingredients they already have.

## Features
- Add pantry ingredients with quantities, units and expiry dates.
- View, edit and delete pantry ingredients.
- Store pantry data using SQLite.
- Suggest recipes based on available ingredients.
- View recipe descriptions and required ingredients.
- Save user profile information through Settings.

## Technologies Used
- Java
- Android Studio
- Android SDK
- SQLite
- SharedPreferences
- Git and GitHub

## How to Run
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the application on an Android emulator or compatible device.

## Project Structure
- `MainActivity.java` — main dashboard and pantry list.
- `DatabaseHelper.java` — SQLite database operations.
- `AddIngredientActivity.java` — add pantry ingredients.
- `EditIngredientActivity.java` — edit pantry ingredients.
- `RecipeRepository.java` — recipe data.
- `RecipeSuggestionsActivity.java` — matching recipe suggestions.
- `RecipeDetailsActivity.java` — recipe details.
- `SettingsActivity.java` — user settings and profile.
